# components/AGENTS.md

This folder contains reusable UI components.

## Rules

Components must be:

- reusable;
- typed with TypeScript;
- responsive;
- accessible;
- visually consistent;
- clean and easy to understand.

## Component Style

Use premium coffee brand UI:

- rounded corners;
- soft shadows;
- elegant spacing;
- smooth hover states;
- warm colors;
- beautiful typography;
- light/dark theme support.

## Recommended Components

Create reusable components like:

- `Button`;
- `Container`;
- `SectionHeading`;
- `ThemeToggle`;
- `Navbar`;
- `MobileMenu`;
- `ProductCard`;
- `OfferCard`;
- `ReviewCard`;
- `SocialLinks`;
- `ContactCard`.

## Important

Do not create many similar duplicated components.
If two components are almost the same, create one flexible reusable component.

## Accessibility

- Buttons must be buttons when they perform actions.
- Links must be links when they navigate.
- Add `aria-label` for icon-only buttons.
- Keep good contrast in light and dark themes.
