# docs/AGENTS.md

This folder contains project documentation.

## Rules

Keep documentation clear and useful for the developer and client.

Recommended docs:

```txt
docs/
├── PROJECT_OVERVIEW.md
├── SETUP.md
├── DEPLOYMENT.md
├── ADMIN_GUIDE.md
├── DATABASE.md
└── CLIENT_NOTES.md
```

## PROJECT_OVERVIEW.md

Explain:

- what Time Coffee website is;
- main features;
- stack;
- project goal.

## SETUP.md

Explain:

- how to install dependencies;
- how to run locally;
- required environment variables.

## DEPLOYMENT.md

Explain:

- how to deploy to Vercel;
- how to connect domain;
- what DNS records are needed later.

## ADMIN_GUIDE.md

Explain for the client:

- how to login;
- how to edit menu;
- how to change prices;
- how to update contacts;
- how to manage offers.

## CLIENT_NOTES.md

Keep important client decisions:

- domain: timecoffee.shop;
- hosting/domain provider: Hostinger;
- deployment target: Vercel;
- website type: premium coffee brand website;
- ordering: WhatsApp / Telegram;
- payment: not required at MVP stage unless client requests later.
