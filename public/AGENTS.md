# public/AGENTS.md

This folder contains public assets: images, icons, fonts, and static files.

## Rules

Assets should support the premium coffee brand style.

Use optimized images:

- coffee cups;
- coffee beans;
- cafe interior;
- barista;
- desserts;
- cozy atmosphere;
- premium backgrounds.

## Image Rules

- Use descriptive filenames.
- Avoid huge unoptimized images.
- Prefer modern formats when possible.
- Keep images organized.

Recommended structure:

```txt
public/
├── images/
│   ├── hero/
│   ├── menu/
│   ├── gallery/
│   └── backgrounds/
├── icons/
└── logo/
```

## Visual Direction

Images should feel:

- warm;
- premium;
- cozy;
- realistic;
- coffee-focused;
- not cheap stock style.
